# ArchiGen Support

Official public technical support and issue tracker for ArchiGen.

## What to use this repository for

- Report technical bugs
- Ask technical support questions
- Request product improvements

## Before opening an issue

- Search existing issues to avoid duplicates
- Include clear steps to reproduce
- Add screenshots or short recordings when possible
- Include environment details (OS, browser, device)

## Response time

- Standard response target: 24-72 hours
- Critical outages are prioritized

## Support scope

This repository is for public technical support only.
Do not post passwords, API keys, personal data, or confidential project files.
